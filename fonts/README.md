# Шрифты TTWellingtons

В этой папке должны находиться файлы шрифта TTWellingtons.

## Необходимые файлы:

Для корректной работы сайта добавьте следующие файлы шрифтов:

- `TTWellingtons-Light.woff2` (или `.woff`, `.ttf`)
- `TTWellingtons-Regular.woff2` (или `.woff`, `.ttf`)
- `TTWellingtons-Medium.woff2` (или `.woff`, `.ttf`)
- `TTWellingtons-SemiBold.woff2` (или `.woff`, `.ttf`)
- `TTWellingtons-Bold.woff2` (или `.woff`, `.ttf`)

## Форматы файлов:

Приоритет форматов (в порядке предпочтения):
1. `.woff2` - самый современный и компактный формат
2. `.woff` - хорошая совместимость
3. `.ttf` - универсальный формат

Если у вас есть только один формат, он будет использоваться. Если есть несколько форматов, браузер выберет наиболее подходящий.

## Примечание:

Если файлы шрифтов отсутствуют, браузер будет использовать резервный шрифт `sans-serif`.
